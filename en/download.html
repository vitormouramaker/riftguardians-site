How to verify the file

The SHA-256 code proves that the file you downloaded is identical to the one we published. On Windows, open PowerShell in the download folder and run:

Get-FileHash .\RiftGuardians-0.9.0-setup.exe -Algorithm SHA256

Compare the result with the code on this page (upper and lower case do not matter). If it is different, do not open the file and let us know. The help page explains it in more detail.
