What this page shows

The installed game reads a small public file to learn the server address, the newest version and whether there is maintenance. This page reads the same file and shows its contents as text. It is hosted outside the game server, so it stays available even when the server is down.

StatusWhat it meansWhat keeps working
WorkingOnline account, PvP, friends and mail are up.Everything.
Under maintenanceThe server is closed for a while.The campaign. Progress is sent when the server is back.
FullThere are more people than the machine can handle right now.The campaign and, for those already in, the online account.
Online PvP pausedThe Duel and Arena queue is switched off.Campaign, online account, friends and mail.

Honest limits

  • The file is updated by hand. A sudden outage may take some time to show up here.
  • The server is a small machine looked after by one person. An outage in the middle of the night (Brazil time) may wait until morning.
  • This page does not check the file's digital signature (the game does). It is for information only.
  • The file is encoded; if you open it directly you will see base64 text. The script on this page only decodes and displays it.

When you check the status, your browser makes a request to GitHub Pages, which hosts the file. GitHub receives your IP address, like any site you visit. This page uses no cookies and stores nothing in your browser.

If the status says "Working" and you still cannot play online, see Support.
