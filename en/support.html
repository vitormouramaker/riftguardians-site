Support and frequently asked questions

Rift Guardians is made and maintained by one person. We reply as soon as we can; a message sent in the middle of the night (Brazil time) waits until the next day.

Account

How is the account created?

The first time you open the game with an internet connection and accept the terms, the game creates a key on your computer and registers an account on the server with it. We do not ask for an e-mail or a password. Your display name starts as "Guardião" ("Guardian") and can be changed in your profile.

I switched computers or reinstalled Windows. What about my account?

The account lives on the computer (and the Windows user) where it was created: the key is stored encrypted for that user, and copying the files to another computer does not bring the account along. To take the account somewhere else there are two codes, created in the game under Settings → Online account → Protect the account:

  • Recovery code (7 groups of 4 characters): it does not expire. Create it and keep it outside the computer — on paper or in a password manager. It is what brings the account back if the computer is wiped, replaced or lost.
  • Transfer code (4 groups of 4 characters): valid for 10 minutes. It is for switching computers right now, with both at hand.

On the other computer, open the game and choose I accept and already have an account on the welcome screen (or Settings → Online account → I already have an account) and enter the code. You can paste it with or without dashes.

Good to know:

  • The code appears once on screen. We do not keep it and cannot show it again. Lost it? Create another one (the previous one stops working).
  • Whoever has the code takes the account. Do not show it or send it to anyone. We never ask for your code.
  • Each code works once. After using the recovery code, create a new one on the new computer.
  • Accounts are never merged. If the computer where you enter the code already has an account with progress, the game warns you and asks for confirmation: it is replaced by the account of the code.
  • When the account signs in on the new computer, the old one leaves it.

I lost the computer and had no recovery code.

In that case the account cannot be recovered. We keep no e-mail or any data that proves who you are, so we have no way of handing an account back to whoever asks. You can start a new account — and create the recovery code right at the start.

The game says "This account moved to another computer".

Someone used a recovery or transfer code of this account on another computer (usually you). The game does not create a new account on its own; it asks what to do: recover with a code (brings the account back to this computer), start a new account on this computer (from scratch) or play only on this computer (no online account). If it was not you, write to the contact address and tell us your friend code.

The game says "Invalid code" or "Too many attempts".

  • Check the characters: after the second group there is no 0, 1, I or O.
  • The transfer code expires in 10 minutes; each code works only once; creating a new code voids the previous one of the same kind.
  • After several wrong attempts, the server blocks new attempts for that account for up to an hour — even with the right code. Wait for the time the game shows.

The game did not accept my name, or my name was changed.

The display name has 3 to 20 characters, using only letters, numbers, space, period, hyphen and underscore, and it cannot impersonate the game's team. A name that breaks the Rules of conduct may be replaced with a neutral name by moderation; in that case the game tells you and name changes are locked for a while, with the date shown on the Profile screen.

The game says "Online modes suspended".

Moderation has suspended the account's online PvP, challenges and friend requests. The game shows until when and the reason, under Settings → Online account. The campaign, the collection and the mail keep working. If you think it was a mistake, write to the contact address with your friend code.

Does reinstalling or updating the game delete my account?

No. Your progress and the account key live outside the game folder, in your Windows user's data folder:

%USERPROFILE%\AppData\LocalLow\Vitor Moura\Rift Guardians

Updating, reinstalling or moving the game folder does not touch that folder. If you delete that folder, you lose the local progress and this computer's account key.

How do I see, export or delete my data?

In the game, under Settings → Online account:

  • Download my data writes a file with everything the server stores about your account.
  • Delete my online account erases the account from the server, after two confirmations. It cannot be undone.

More details in the Privacy Policy.

Playing offline

Can I play without an internet connection?

Yes. The whole campaign works offline. What you play goes into a queue on your computer and is sent to the server when the connection returns.

What needs the internet?

The online account, online PvP, friends, challenges and in-game mail.

I played offline and my progress did not show up in the online account.

Sending happens automatically when the game can reach the server. Open the game with an internet connection and wait a little in the lobby; under Settings → Online account you can see the queue and ask it to synchronize. The server checks every stage by replaying the match, so very old stages, or stages from an earlier version of the game, may be refused.

Server

The game says "Server under maintenance", "Server full" or "Online PvP is paused".

That is a notice from us, not a fault in your computer. The campaign keeps working and your progress is uploaded when the server is back. See Server status for more.

The game says "Server full — trying again" or "Queue full right now".

The server has a limit of players connected at the same time. When it fills up, whoever arrives waits: the campaign goes on as usual on your computer, progress is kept and sent when a spot opens, and the game tries again on its own. "Queue full" means only online PvP matches are at the limit; try again shortly.

The game tells me to update.

A new version is out. Download it from the Download page and install it over the old one: progress is not deleted. When an update changes the rules of the game, online modes only come back after you update; the campaign stays playable.

I cannot get into online PvP matches.

  • Check the Server status.
  • PvP uses UDP port 7778. School, work or internet-café networks, and some firewalls, block that kind of traffic. Try another network if you can.
  • Online modes open up with your account level; the game shows the level required on each card.

My connection dropped in the middle of a PvP match.

You have 90 seconds to return: open the game and use the "Return to the match" card in the lobby. After that the match counts as abandoned, and repeated abandons increase the wait to join the queue.

Installation

Windows showed a blue warning when I opened the game.

That is expected. See The Windows warning.

My antivirus blocked the game.

Do not turn off your antivirus. See what to do and let us know.

How do I uninstall?

In Windows Settings → Apps → Installed apps, look for Rift Guardians. If you used the portable version (.zip), just delete the game folder. Uninstalling does not delete the account on the server: for that, use Delete my online account inside the game before uninstalling.

How to report a bug

A good report saves several back-and-forth messages. Send to the e-mail or to Discord:

  1. The game version, shown in the corner of the lobby and in Settings.
  2. What you were doing: stage, commander, mode (campaign, Heroic, Duel, Arena).
  3. What happened and what you expected to happen.
  4. A screenshot, if you can.
  5. If the game closed by itself or froze, the log file Player.log, which is in the data folder shown above.

Before sending Player.log, be aware that it contains technical information about your computer (graphics card model, Windows version, folder paths that include your user name). Do not send the files online.json or profiles.db: they do not help with diagnosis and they contain your account's key and progress.

Reporting an offensive name

Send the player's friend code or name to the contact e-mail, with a screenshot if possible. See the Code of conduct.
