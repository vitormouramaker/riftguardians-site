O aviso do Windows ao abrir o jogo

Resumo

O Windows mostra um aviso ao abrir o instalador (ou o jogo) pela primeira vez porque o Rift Guardians é um jogo gratuito feito por uma pessoa e não tem assinatura digital, que é um serviço pago todo ano. O aviso não diz que há vírus: diz que o Windows ainda não conhece este arquivo.

Para continuar: clique em Mais informações e depois em Executar assim mesmo.

Se preferir não confiar só na nossa palavra, você pode conferir o código SHA-256 do arquivo ou instalar pelo aplicativo do itch.io.

Passo a passo

As imagens acima são desenhos ilustrativos, não capturas de tela. Vamos trocá-las por fotos reais depois do teste em computadores com o Windows recém-instalado. Os textos podem variar um pouco conforme a versão do Windows e o idioma.

Antes disso, o navegador também pode avisar que "este arquivo não é baixado com frequência". Se isso acontecer, escolha Manter (o texto muda conforme o navegador).

Por que o aviso aparece

  • O filtro do Windows (Microsoft Defender SmartScreen) confia nos programas pelo histórico: um arquivo novo, que pouca gente abriu, é mostrado como "não reconhecido".
  • Um programa assinado leva o nome de quem publicou e acumula esse histórico de uma versão para a outra. A assinatura é um certificado pago e renovado todo ano. O Rift Guardians é gratuito e não tem receita, então hoje não temos esse certificado.
  • Sem assinatura, cada versão nova é um arquivo novo para o Windows. O aviso volta quando você atualiza.
  • "Fornecedor desconhecido" quer dizer exatamente isso: o arquivo não tem assinatura. Não é resultado de uma análise do conteúdo.

O aviso existe por um bom motivo e não pedimos que você o ignore sem pensar. Baixe o jogo só pelos endereços da página Baixar e, se quiser ter certeza, confira o arquivo.

Como conferir o arquivo (SHA-256)

O SHA-256 é um código calculado a partir do arquivo. Se um único byte mudar, o código muda. Publicamos o código de cada arquivo na página Baixar.

  1. Abra a pasta onde o arquivo foi baixado (normalmente Downloads).
  2. Clique com o botão direito num espaço vazio da pasta e escolha Abrir no Terminal (no Windows 10: segure Shift, clique com o botão direito e escolha Abrir janela do PowerShell aqui).
  3. Digite o comando mostrado logo abaixo, trocando o nome se o seu arquivo for outro, e aperte Enter.
  4. Compare o código que aparece na coluna Hash com o da página Baixar. Maiúsculas e minúsculas não importam.
Get-FileHash .\RiftGuardians-0.9.0-setup.exe -Algorithm SHA256

Se o código for igual, o arquivo é exatamente o que publicamos. Se for diferente, não abra: apague, baixe de novo pelo link oficial e, se continuar diferente, fale com a gente.

Instalar pelo aplicativo do itch.io

O aplicativo do itch.io é um programa do próprio itch.io que baixa, instala e atualiza jogos. Você instala o aplicativo uma vez, procura o Rift Guardians nele e clica em instalar.

Ainda não medimos se o aviso do Windows deixa de aparecer para quem instala por esse caminho. Quando tivermos testado, esta página dirá o resultado.

Não há botão para continuar

Em computadores com Windows 11 e o Controle Inteligente de Aplicativos ligado, o Windows pode bloquear o jogo sem oferecer o botão "Executar assim mesmo". Esse recurso bloqueia programas sem assinatura que ainda não são conhecidos.

Só você pode decidir o que fazer com as proteções do seu computador. O recurso fica em Segurança do Windows → Controle de aplicativos e do navegador → Controle Inteligente de Aplicativos. Em algumas versões do Windows, depois de desligado ele não pode ser ligado de novo sem reinstalar o sistema — leia a explicação que o próprio Windows mostra antes de mexer. Se não quiser mudar isso, não mude: esperamos conseguir assinar o jogo no futuro.

Se o antivírus reclamar

Jogos feitos na Unity e sem assinatura às vezes são marcados por engano.

  • Não desligue o antivírus. Nunca vamos pedir isso.
  • Confira o SHA-256 do arquivo que você baixou.
  • Experimente a versão portátil (.zip) da página Baixar: ela costuma dar menos alarme falso que o instalador.
  • Avise a gente dizendo qual antivírus, qual mensagem e qual versão do jogo. Com isso enviamos o arquivo ao fabricante do antivírus como detecção incorreta.

Resumo honesto

  • O aviso azul vai aparecer para todo mundo enquanto o jogo não tiver assinatura digital.
  • Ele volta a cada versão nova.
  • Você não é obrigado a continuar. Se ficar em dúvida, não instale e pergunte no suporte.
